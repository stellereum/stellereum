# AGENTS.md — Constitution (HDAE Phase 6, 2026-10-29)

## 1. Zero narrative handoffs
No `.md`/`.txt` diaries. Progress = tests + `STATUS.md` (machine-generated by
`./scripts/harness_status.sh` — hand edits to it fail review). Technical truth
lives in `docs/specs/` (start with `00_PROJECT_MAP.md`); what-to-do lives in
`docs/ROADMAP.md`; everything else is `.archive/`.

## 2. Strict scope isolation
Work only inside your assigned crate/file set (`TASK_PROMPT_TEMPLATE.md` line 1).
Out-of-scope edits fail review even if correct. `stellereum_head/` and `w8/`
are stale copies — never touch, never import.

## 3. Zero tolerance for fake code
`todo!()`, `unimplemented!()`, `FIXME`, `XXX`, dummy returns, or weakening a
test to make it pass = immediate failure. Judgment lints get per-item
`#[allow(lint)] // GATE: <reason>` — never a blanket allow, never a refactor
you cannot prove (differential test or revert).

## 4. Mandatory gate execution
A task is NOT complete until the gate is green — paste the output:
- `cargo clippy --all-targets -- -D warnings` → 0 warnings, 0 errors
- `cargo test --no-fail-fast` on your scope → green
- consensus-adjacent → sim harness (`consensus_liveness_harness`) green
Full command: `./scripts/verify_testnet_ideal.sh` (`--fast` for iteration).

## 5. Honest numbers
Report measurements only from pasted command output. Unverified claims are
marked UNVERIFIED. Refusals (with reasons) are valid output.

## 6. Live cluster is read-mostly
No restarts/txs/stakes/key operations without explicit human order. Never
delete live store data, the running binary, or the only snapshot.

## 7. Frozen core
Wire format, quorum values, apply(), mempool admission, staking math,
signature domains — change only with spec update + audit note + full gate.

## 8. Worktrees (orchestrator-only rule)
Workers NEVER create, manage, or leave their worktree: you wake up inside your
assigned directory and work only inside your scope lock. Isolation is the
ORCHESTRATOR's job (human or lead agent): it runs
`scripts/agents/spawn_worktrees.sh <id> <scope>` per worker and merges via
`scripts/agents/merge_verified.sh`. If you find yourself without a worktree
(single-tree session), the equivalent rule is: disjoint file sets per agent,
`cargo clippy --fix` is forbidden (shared lock), verify with file-scoped grep.

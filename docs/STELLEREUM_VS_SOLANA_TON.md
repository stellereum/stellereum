# Stellereum (Ruleset v7) vs. Solana vs. TON

**Scope & Evidence Basis:** Factual comparison grounded strictly in repository documents, specs, CI/test configs, and verified Wave 1–8 outputs as of **2026-11-25**. Where live capacity measurements have not yet been executed (notably `scripts/perf-matrix.sh`), cells are explicitly marked `NOT MEASURED YET` with no extrapolation or fabricated numbers.

---

## 1. Executive Summary

- **Stellereum (Ruleset v7, `FORK_ID = 0x3ae00ebc`, Chain `5757`)** is a single-client, Tendermint-style two-phase BFT Layer 1 enforcing **FULL-PQ cryptography end-to-end** (`Falcon-512` FIPS 206 for all transactions and consensus votes/QCs; `ML-KEM-768` FIPS 203 for `infnode` P2P ephemeral key exchange and E2E mail/storage; classical Ed25519/BLS vote lanes deleted). It executes deterministic WASM contracts via `wasmi` alongside native orderbook CLOB, PMM, bridge v2, and cross-shard 2PC modules, operating today on a 4-validator public testnet (`A/B/C/D`, shard `0` active, shard `1` parked) with `ops/status/status_server.py`, nginx reverse-tunnel RPC LB, `stellereum-upgrader`, and 10 `cargo-fuzz` targets (`23,550,124` executions, `0` crashes). See [`docs/RULESET_V7.md`](RULESET_V7.md) and [`docs/TESTNET_STATUS.md`](TESTNET_STATUS.md).
- **Solana (Agave / Tower BFT → Alpenglow/Votor)** optimizes for extreme slot cadence and parallel execution (`Sealevel` / SVM): transitioning in Oct 2026 (epoch `1064`, slot `459,653,000`) from Tower BFT (`~400 ms` slots, 32-vote lockouts, `~12.8 s` rooted finality) to Votor (`1–2` voting rounds per slot, off-chain BLS footer certificates, `80%`/`60%` thresholds, `~150 ms` target finality, classical Ed25519 + BLS). See [`docs/BFT_COMPARISON.md`](BFT_COMPARISON.md) and [`docs/TESTNET_UX_COMPARISON.md`](TESTNET_UX_COMPARISON.md).
- **TON (Catchain 2.0 / MyTonCtrl / TVM)** pairs Catchain 2.0 BFT across a masterchain + dynamic workchain shardchains (production cap `16` shards, typically `4–8` active) with the asynchronous message-passing `TVM` (BoC cells + bounce semantics), classical `Ed25519` signatures, `MyTonCtrl` validator operations, `check_ef` efficiency tracking, and TON Streaming v2 (`pending`/`confirmed`/`finalized` + `trace_invalidated`). See [`docs/program/ENTERPRISE_WAVES.md`](program/ENTERPRISE_WAVES.md) and [`docs/audits/COMPREHENSIVE_AUDIT_REPORT.md`](audits/COMPREHENSIVE_AUDIT_REPORT.md).

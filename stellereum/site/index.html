Zero to a transaction in three steps

The commands below are in the repository. Testnet STELL has no value. Use keys you can lose. One finalized block is final.

  1. 01

    Connect a network

    Point a wallet or the Rust SDK at rpc.stellereum.org with chain ID 5757 and the symbol STELL.

  2. 02

    Request test STELL

    The public faucet sends 5 STELL per address every 45 minutes, with 20 requests per hour per IP and a 1,000 STELL lifetime cap.

  3. 03

    Send a transaction

    Build with the SDK, sign with a Falcon-512 key, and submit over stell_sendRawTransaction.

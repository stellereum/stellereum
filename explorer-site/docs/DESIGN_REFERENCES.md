# Дизайн-референсы (сверка вживую, октябрь 2026)

Скачано и просмотрено полностью (HTML + стили + API-прелоады):
- `https://tonviewer.com` (Next.js, таблицы транзакций, каталог, строгий светлый UI)
- `https://gram.org/explorer` (SPA, прелоад `/api/stats`, `/api/blocks/latest`, `/api/transactions/latest`, realtime)
- `https://eth.blockscout.com` (EVM-эксплорер, плотные статистики)

## tonviewer.com — что берём

- Шапка: лого + большой поиск по центру (`Search`, hotkey `/`), иконки справа. У нас так же.
- Хлебные крошки: `Main / Last Transactions`. У нас: `Home / Blocks / Block #…` и т.д.
- Таблица транзакций: колонки **Date | Hash | Account | Fee | Value**, короткие хеши `26efb994…1777b383` + иконка копирования, имена (`starsbuy.ton`, `Elector Contract`) вместо сырых адресов где возможно.
- Строгая типографика, много воздуха, светлая тема по умолчанию + тёмная.
- Футер: Terms / Privacy / Report Issue.

Не берём: рекламу Keeper, каталог DEX/NFT, лишние разделы.

## gram.org — что берём

- Главная — максимально простая: realtime-ленты нативных Stellereum-блоков (`stell_latestBlocks`) и счётчиков транзакций.
  - Одна лента **Latest Blocks** + панель валидаторов рядом (на мобиле — друг под другом), автообновление каждые ~4с, переключатель Live/Pause, пульс-индикатор.
- Красивые **карточки кошельков**: баланс крупно, график/активность, табы Activity / Tokens / Contract.
  - У нас: страница Address с карточкой баланса + табами Transactions / Details.
- Прелоад данных в `<head>` и лёгкий SPA-бандл. У нас: Vite SPA + параллельные `Promise.all` RPC-запросы.
- API-формы, которые подсмотрели: `/api/stats`, `/api/blocks/latest?limit=12`.
  - Маппим gram-карточки на нативные запросы: `stell_blockNumber`, `stell_latestBlocks`, `stell_getBlock`, `stell_getValidators`.

Не берём: TON-специфику — shard/workchain нет; цепь одна (chainId 5757), сохраняем только двухколоночный ритм.

## eth.blockscout.com — что берём

- Строка ключевых метрик: высота / block time / fee (nano-STELL) / validators — **одной строкой карточек**, без перегруза.
- Страницы Block / Tx: высота, хеш, время, счётчик транзакций; статусы через `stell_getTransactionStatus`, детали через `stell_getTransactionReceipt`.
- Технологичный моноширинный шрифт для хешей/адресов.

Не берём: перегруженные сайдбары, десятки таблов, контракт-верификацию в v1.

## Итоговый баланс (наш UI)

1. Простота gram (2 колонки live) +
2. Строгость tonviewer (таблицы, поиск, крошки) +
3. Информативность blockscout (1 строка статов, детали блока/tx моноширинно).

Тёмная/светлая тема, адаптив: ≥1024px — 2 колонки; <1024px — 1 колонка; таблицы → карточки на <640px.

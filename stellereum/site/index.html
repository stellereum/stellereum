Reference host measurement: 571–792 TPS on a Ryzen 5 3600, 6-core / 16 GB. A 1 vCPU validator is explicitly insufficient for consensus (docs/site/04-validators.md, Hardware). No figure here is a mainnet promise.

  • 01

    No external audit

    Internal review waves and 36 documented known issues exist. No independent party has attested the code.

  • 02

    No L2 execution

    The shard layer only orders external L2 batches. Data availability, bridging and execution are out of scope. No shard split has ever run on a live network.

  • 03

    No shielded transfers

    The shielded-transfer module was deleted. Stealth-address prototypes exist; they hide the address, not the amount.

  • 04

    No EVM contracts

    The EVM adapter reads balances and settles bound value transfers. It cannot deploy or call Solidity.

  • 05

    zkML is not ZK

    Verification re-executes the model. There is no succinct proof, no trusted setup and no hiding.

06Roadmap//Tracked in the open

From testnet to mainnet

Statuses describe the current tree. A ruleset change is a hard fork with a new genesis, not an in-place upgrade.

  1. 01

    Testnet launch

    Shipped

    Genesis ruleset v5 is live on chain 5757. Falcon-512 votes and the 1B STELL cap are in force. No external audit has been completed.

  2. 02

    Independent validators

    In progress

    Operators run nodes on separate hosts. A new node joins through the operator runbook and an admin-provided peer set; there is no public permissionless join flow.

  3. 03

    Upgrade and lifecycle

    Queued

    Binary upgrade execution is off by default and must be enabled at genesis. Commission change and redelegation have ledger code but no opcode, RPC or wallet path.

  4. 04

    Mainnet

    Queued

    Blocked by an external audit, public endpoint hardening, and the upgrade and validator lifecycle gaps. No date is set.

--------------------------------------------------------------------------------
1. МУЛЬТИЧЕЙН APK-КОШЕЛЁК (STELL WALLET ANDROID)
--------------------------------------------------------------------------------

Концепция кошелька:
• Фокус и акцент: Нативная экосистема Stellereum (STELL) и её специализированные
  L2-токены (L2-Private, L2-AI, L2-Speed/Gaming, STS-стандарт).
• Мультичейн-подключения:
  - Интеграция TON Connect (для dApps сети TON и Telegram).
  - Интеграция WalletConnect / EIP-1193 (для Base / Ethereum).
• ПРИНЦИПИАЛЬНОЕ РЕШЕНИЕ: TON Connect и внешние сети реализуются НАПРЯМУЮ,
  а НЕ через Account Abstraction Stellereum, так как заворачивать чужие протоколы
  в нашу AA нелогично — они должны говорить на своих нативных стандартах.
• Архитектура:
  - Мобильное приложение под Android (APK).
  - Поддержка постквантовых ключей Falcon-512 по умолчанию.
  - Показ нативных балансов, скрытых балансов (Confidential notes) и L2-токенов.


--------------------------------------------------------------------------------
2. ЭТАП 1: ЗАПУСК ПЕРВОГО ПОЛНОЦЕННОГО ТЕСТНЕТА (PUBLIC TESTNET)
--------------------------------------------------------------------------------

Поскольку базовое L1 ядро блокчейна полностью готово, переходим к запуску тестнета
по всем правилам распределённых сетей:

[ ] 1. Чистый постквантовый генезис (Genesis v5):
    - Полная зачистка остатков не-PQ кода в генезисе.
    - Все стартовые валидаторы изначально инициализируются на Falcon-512 ключах.
[ ] 2. Сетевая инфраструктура и топология:
    - Развёртывание 4 независимых валидаторов (кворум 3-из-4) для отказоустойчивости.
    - Настройка публичных DNS-сидов (Seed Nodes) и P2P-федерации.
    - Привязка официальных доменов к RPC и эксплореру.
[ ] 3. Публичные шлюзы:
    - Защищённый публичный RPC-шлюз (через Cloudflare Web3 / Edge с защитой от DDoS).
    - Веб-эксплорер блоков и транзакций.
    - Публичный портал фаусета (Testnet Faucet с капчей и IP-лимитами).


--------------------------------------------------------------------------------
3. ЭТАП 2: ВЫКАТКА ИННОВАЦИЙ ПРЯМО В ТЕСТНЕТ
--------------------------------------------------------------------------------

Все запланированные инновации теперь выкатываются не в вакууме, а на работающей
живой сети тестнета через сетевые обновления:
• Communication Grants (антиспам-связь без почты).
• Нативный Account Abstraction (смарт-аккаунт, ротация ключей, Paymaster gasless).
• Специализированные L2 (L2-Private Dark Pool, L2-AI zkML, L2-Gaming).
• Оптимистичные мосты к Base (Coinbase) и TON.


--------------------------------------------------------------------------------
4. ЭТАП 3: ВЕБ-ПРИЛОЖЕНИЯ, САЙТ И ПОЛНОЦЕННЫЙ РЕЛИЗ
--------------------------------------------------------------------------------

[ ] 1. Официальный портал и сайт проекта (презентация технологий, документация).
[ ] 2. Веб-кошелёк (Web Wallet) и мобильное Android APK приложение.
[ ] 3. Разработка ключевых смарт-контрактов экосистемы:
       - Контракты пулов ликвидности и DEX-интеграций.
       - Шаблоны контрактов токенов STS (аналог ERC-20 / Jetton).
       - Контракты мостов к Base (Solidity на OP Stack) и TON (FunC Jetton Bridge).
[ ] 4. Интеграции для бирж:
       - Стандартизированный JSON-RPC / Rosetta API для быстрого листинга CEX.
       - TypeScript / Python SDK (@stellereum/sdk) для разработчиков и ботов.

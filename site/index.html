Protocol

The base layer, hardened end to end

Six decisions that define Stellereum: no legacy curves, a quantum-compact committee, parallel execution and confidentiality that ships with the chain.

Pure Post-Quantum

Validator votes are signed with Falcon-512 and Ed25519 signatures are rejected at the protocol level, so no legacy curve can weaken consensus.

Falcon-512 signature scheme

PQ-BFT v5 + µQC

The committee of 16 validators is chosen by BLAKE3 sortition and finalises every block through a quantum-compact quorum certificate.

committee 16 · quorum 66.7%

Sealevel-lite

Transactions declare their read and write sets, so independent calls run in parallel. Benchmarked at 5.16× against sequential execution.

5.16× parallel speed-up

SVM + zkML

A Solana-compatible runtime for programs, extended with verifiable zero-knowledge machine-learning inference anchored on chain.

SVM programs · verifiable inference

Confidential transfers

Shielded notes, internally called stealth, hide amounts and counterparties while the total supply stays auditable by anyone.

shielded notes · auditable supply

Bridges & L2

Canonical bridge contracts plus three L2 tracks carry liquidity, privacy and rollup throughput above the base layer.

3 L2 tracks · canonical bridge

Build

From zero to a transaction in three steps

No allowlist, no private RPC. Everything you need is public and works today.

  1. Connect a network

    Point your wallet or SDK at https://rpc.stellereum.org with chain ID 5757 and the symbol STELL.

  2. Get test STELL

    Request gas from the faucet: POST /api/faucet-public/<address> on the testnet host, 5 STELL per address every 45 minutes.

  3. Send a transaction

    Submit a signed transfer over JSON-RPC, then follow it block by block in the explorer until it is final.

Roadmap

From testnet to mainnet

Four steps, tracked in the open. Statuses reflect the current testnet release.

  1. Step 01 Shipped

    Testnet launch

    Genesis v5 is live with Falcon-512 verification and the KAT beacon 61336779…fcd6e.

  2. Step 02 In progress

    Independent validator network

    Independent operators on separate hosts, so fault tolerance stays above the 66.7% quorum line. Admission is operator-managed today and moves to staking-driven onboarding for mainnet.

  3. Step 03 Queued

    Innovations in the live network

    Confidential transfers and SVM tooling already ship in the client; further items land through coordinated network upgrades.

  4. Step 04 Queued

    Mainnet

    Economic security with a 1,000 STELL validator bond, independent operators and production SLAs.
